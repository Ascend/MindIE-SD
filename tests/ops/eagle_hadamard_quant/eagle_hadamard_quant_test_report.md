# EagleHadamardQuant 测试报告

## Test Plan

以下命令从仓库根目录执行。小 shape UT 使用 CPU 和 C++ 编译器。大 shape 测试使用已安装本次 OPP、PyTorch 插件及 msprof 的 Ascend 950 环境，`--device-id 5` 指物理卡 5。

1. **小 shape 精度与接口。** 对照独立标量参考检查旋转、量化编码和 scale，并调用生产 C++ `CheckParams` 检查合法与非法输入。

   ```bash
   python -m pytest -q tests/UT/ops_reference/test_eagle_hadamard_quant_small_shape.py
   ```

2. **大 shape 精度。** 对 3 个生产配置各测 3 种输入。CPU 参考以 FP64 计算旋转，再按 BF16 和目标量化格式编码。对全部行校验 y、每 32 个元素的 E8M0 scale、输出形状、dtype、设备及输入完整性。

   ```bash
   cd tests/ops/eagle_hadamard_quant
   bash run_eagle_hadamard_quant_prod_accuracy.sh --device-id 5 --mode accuracy
   ```

3. **大 shape 稳定性。** 在同一测试目录运行，先校验首轮输出，再固定输入重复执行 1000 次。每轮将 y 和 scale 与首轮逐字节比较，并检查输入未变。

   ```bash
   bash run_eagle_hadamard_quant_prod_accuracy.sh --device-id 5 --mode stress --stress-runs 1000
   ```

4. **大 shape 性能。** 在同一测试目录用 `msprof op` 采集 EagleHadamardQuant 的 `Task Duration(us)`。每次预热 20 轮，每组分两批各独立采集 10 次，取合并 20 个样本的最小值作为执行耗时。

   ```bash
   for batch in 1 2; do
       bash run_eagle_hadamard_quant_msprof_op.sh --device-id 5 --repeats 10 --output "/tmp/eagle-msprof-$batch"
   done
   ```
