MindIE SD Third-Party License Summary
=====================================

This file summarizes third-party dependencies referenced by this repository.
Version numbers are intentionally omitted: open-source licenses rarely change
between versions, and the requirements files use loose constraints, so pinned
versions would drift out of sync. Please verify upstream license terms before
redistribution of binary artifacts.
