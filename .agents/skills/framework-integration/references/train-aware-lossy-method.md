# 方法：训练感知有损优化（换入外部训练权重）

> 定位：**通用方法**，跨框架、跨模型复用。与具体产物隔离——本文件不写具体模型 / 框架 / 权重产品名，
> 也不写实测**加速比**（比例是「模型 × 框架能力 × 负载规模」的函数，不可迁移，纪律见 §6）。
>
> 配套：
>
> - 框架能力支持面 → `framework-support-matrix.md`（「训练感知」表）
> - 某框架的**开启方式**（框架差异）→ 该框架的 enablement 文档（索引见 §7）
> - 组合协议 / 质量门禁 → `dit-perf-opt/references/combination-search.md`、`accuracy-gate/references/quality-gate.md`
> - 产物坐标与实测记录 → 会话产物目录（`{run_results_dir}`），不入 skills

## 1. 分类（与框架无关）

归组是强制的三层：**无损**（`并行` / `kernel融合`）、**免训练有损**（`Cache` / `量化` / `稀疏` /
`时间步优化`）、**训练感知**（换入外部训练权重）。训练感知组的**归组判据 = 是否换入外部训练的权重**：

| 手段 | 换入物 | 机制 |
|---|---|---|
| `少步蒸馏` | 蒸馏得到的少步权重 / 适配器 | 把 denoise 步数预算压到很少的**评估次数**级 |
| `VAE解码替换` | 外部训练的小型自编码器 | 用轻量解码器替换大参数量的原生解码器 |
| `可训练稀疏` | 带稀疏结构的训练权重 | 稀疏度由训练保证，推理侧免校准 |
| `QAT` | 量化感知训练权重 | 低位宽由训练保证 |

- 与免训练组别混：仅推理侧裁剪 / 跳步（**不换权重**）= `时间步优化`；换蒸馏权重 = `少步蒸馏`。
- 换入外部权重的**组件**（如解码器）同样归训练感知组，不因「它是某个大模块的一部分」而归入其他。
- 具体 checkpoint 名 / 结构布局 / 产品名属**实现**，只入报表「说明」列，**不得作特性名**。

## 2. 通用使能回路（四步）

```text
① 核支持面 → ② 验前置契约 → ③ 接入并留计数证据 → ④ 分层验证与声明
```

1. **核支持面**：先查 `framework-support-matrix.md` 该框架列——框架是否**已有**这条链路
   （蒸馏权重链路 / 可替换的组件接口）。状态 `❓` 不等于支持，`❌` 时按缺口补齐策略选
   「跳过 / 走开发 / fork 探针」并留痕，**不静默做**。
2. **验前置契约**：见 §3。三条契约任一不满足，后续所有数字都无意义。
3. **接入并留计数证据**：见 §3.2。权重没生效但请求跑通，是本组最常见的**假加速**来源。
4. **分层验证与声明**：见 §4 / §5 / §6。**先证接口接对，再谈画质档位**。

## 3. 换入权重必须先验的三条前置契约

### 3.1 步数语义契约：评估次数 ≠ 区间数

- 少步权重通常自带**时间步调度元数据**（base schedule）。声明了它时，请求里的步数参数语义 =
  **denoiser 评估次数**，**不是** sigma 区间数 —— 按「区间数 = 评估次数 + 1」的直觉理解会**少跑一步**。
- 另一侧的坑：模型配置若**固化了**调度元数据，请求侧指定步数可能被拒或静默忽略。
  **判据**：装载日志出现调度来源声明，且实际评估次数与请求一致。

### 3.2 装载计数契约：防 no-op 假加速

换入权重的收益必须与**装载证据**绑定，否则「请求跑通」可能只是权重没挂上：

- 目标模块数（实际被替换/适配的模块计数）、rank/形状提升声明、**每个 worker** 的激活记录。
- 缺任何一项 → 该档位只能记为「未生效」，**不得宣称收益**。
- 反向判据见 §4.3：**字节级等价 = 从未生效**（比看加速比可靠）。

### 3.3 组件契约：先读参考实现的判定契约，不要扫参

替换一个组件（解码器 / 采样器 / 编码器）前，**先到参考实现源码里读它对这类 checkpoint 的判定契约**，
至少四项：

| 契约 | 读什么 |
|---|---|
| 张量形状判定 | 用什么 tensor 形状/通道数**识别**这类 checkpoint |
| 构造参数 | 用什么参数（patch / 上采样配置 / 层数）构造，逐 index 是否一一对应 |
| 输入约定 | latent/输入是否被变换（归一化 / 反归一化 / 缩放）**由谁做、做几次** |
| 后处理与输出范围 | 输出是否有界、是否 clamp、后处理是否**权重相关** |

- **契约对不上 = 选错了权重**，扫参不可能补回**架构级错配**（典型：用逐帧 2D 网络去解码一个
  时间压缩过的 latent，缺失的时间维无法用任何输入缩放/激活/上采样组合弥补）。
- 用权重 tensor 名/形状与参数计数**逐位对拍**（`strict` 载入 + 参数量与结构吻合）作为「构造正确」的证据。
- 拿不到真实权重时的**验证上限**：只能验 index 布局（参数化槽位与无参槽位互补）、
  帧数/几何契约、未知布局 **fail-closed**（抛错而非静默误载）；且必须**显式声明「未经真实权重验证」**。

## 4. 通用判定法（三件）

### 4.1 协同定位：比值法 + 机理用逐步墙钟证

- **交互强度 = 实测（该组合）÷ 各单点之连乘**。≈1 = 独立（可连乘估算）；明显 >1 = 正协同；
  <1 = 相互稀释。三元组合再用「两两 × 剩余单点」看能否**完全解释**（能否 = 归因完成）。
- **别停在相关性**：用**逐步墙钟**（每步耗时 / 每阶段耗时）说明机理。典型可证机理：
  某维度的**边际收益随另一维度加压单调上升**（Amdahl）—— 表现为正协同。
- **工程含义（可迁移）**：某维度**单点收益低 ≠ 可裁**。按单点收益裁剪候选会误删正协同来源；
  裁剪判据应看「边际收益随其他维度加压的变化方向」。
- 单点收益排序**随负载规模（时长/分辨率/序列长/拓扑）反转**：序列变长会把计算推向注意力一侧，
  削注意力的维度受益上升、线性层类维度占比被稀释。**本任务口径下必须自己测单点，不引用别处的排序。**

### 4.2 质量分层：接口正确性 → 画质档位（顺序不可颠倒）

| 层 | 问什么 | 判据 |
|---|---|---|
| ① 接口正确性 | 「接对了吗」 | **同输入对拍**：逐帧/逐像素**相关系数**（对全局尺度不变 ⇒ 只反映内容是否对上）；输出 **std / mean / 被钳位像素占比**与原生组件**同量级** |
| ② 画质档位 | 「画质值多少」 | 与原生组件对拍 SSIM/LPIPS + 视觉门 → 落成档位声明（**预览级 / 保画质**） |

- **PSNR 不可用于判「接错」**：预览级组件天然丢高频，PSNR 明显偏低是**预期**而非故障。
  用 PSNR 判接错会把排障引向错误方向。
- 相关系数**对尺度不变**，所以它判「接对与否」，**不判画质好坏** —— 两层各用各的指标，别混。
- 换入组件被判为预览级时，报表**必须并列两条部署建议**（保画质档 / 预览档）。
  只报最高加速比而不给保画质档 = 交付缺失。

### 4.3 「未生效」判据：字节级等价

- 开 / 关某维度、两次**独立**运行产出的产物 **md5 相同**、质量指标同值 ⇒ 该维度**从未生效**。
  此时应把它**整体剔除**，而不是记成「收益近似为零」。
- 为什么需要这条：某些有损维度的预热/预算参数会**吃满**少步档的全部步数预算 ⇒ 该维度在少步档
  结构性地无法生效。**字节级等价是比加速比对比更强的未生效证据。**

## 5. 通用归因链：「块状 / 过曝 / 内容错」按代价从低到高

1. **输出范围与钳位占比**（最便宜、最常命中）：被替换组件的**末层往往无激活**，输出**无界**；
   照抄参考实现的 `clamp(0,1)` 会把大比例像素钉成纯黑/纯白，观感即大片斑块。
   参考实现的默认后处理常是**权重相关**的 ⇒ **换 checkpoint 必须重新验证输出范围**
   （本例改为逐帧百分位拉伸后，钳位占比从两成多降到 1% 量级、对比度与原生对齐）。
2. **空间自相关 lag 剖面**：看是否有周期尖峰 —— 区分「上采样块伪影」与「内容错」
   （剖面平滑衰减、无 lag=倍率尖峰 ⇒ 排除最近邻上采样的块伪影；换插值模式结果不变也支持此判定）。
3. **结构误读**：把无参槽位当成上采样层之类 ⇒ 空间倍率错（对照参数计数即可发现）。
4. **输入约定**：最后才查归一化/缩放次数（§3.3）。多算一次归一化会**过驱动**头部非线性
   （如 `tanh` 类饱和），表现为内容对不上 + 钳位占比暴涨。
5. **几何/帧数契约**：解码器替换还要对齐**帧数映射**（latent 帧 → 输出帧），错配表现为长度或
   首尾帧错位。

## 6. 通用声明纪律

- **数字纪律：看趋势与量级，不看绝对值**——
  - **不写入**：**绝对耗时**（具体秒数 / 每步毫秒数）与**绝对质量分值**（`PSNR` / `SSIM` 的具体读数）
    ——只在本次环境成立，写进 skills 会被误读为该组合的预期值；
  - **要写入**：**大致加速比**（量级/约数：「约 3 倍」「两位数倍」「一个数量级」）与
    **质量变化度**（相对基线的**差值/降幅**：「SSIM 降约 0.2」「PSNR 降约 4 dB」「质量基本无感」）
    —— 这两类才是跨组合可读的信息；
  - **比例关系**（案例说明的核心）：单点收益**排序**、独立性 / 协同强度（「≈1 独立可连乘」「某两维
    呈正协同」）、组合能否由「两两 × 剩余单点」**完全解释**、某阶段是否为端到端节省的**全部来源**、
    收益随规模**线性还是反转**；
  - **方向选择**：采纳哪一档、为何、回退了什么、资源下一步投向哪里 —— **并标注「本组合观测」**；
  - **判定以最新数据为准**：策略与方向结论每次按**最近一次实测**重判，案例历史结论只作参照，
    **不得替代本任务复测**。
- **方向必须动态优选，禁止路径固化**（本组最容易写错的一条）：**同一方法在不同框架下由不同
  「能力实体」承载**（融合 op / eager 路径 / 框架自带开关 / 待开发缺口），**收益因此不同，优选方向
  也随之不同** ⇒ **不得把某个模型的优化路径写成 skills 里的固定路线**。
  - 技能只固定**判据与流程**：① 本任务口径下测单点（不引用别处排序）→ ② 比值法定协同 →
    ③ 结合能力面（`framework-support-matrix.md` 该框架列）与本任务实测收益 → ④ **在任务内定方向**；
  - 换框架 / 换模型 / 换负载规模（时长、分辨率、序列长、拓扑）= **重判方向**；
  - 案例里的方向结论一律读作「**该框架 × 该模型 × 该规模下的观测**」，不是可复制的执行序。
- **单点结论不跨规模迁移**；换分辨率 / 时长 / 拓扑 = 新对照。
- **探针与经验分开**：未合入上游 / fork 补丁 / 默认关 / 用后即弃的载体标 `[探针]`，
  由它发现的 durable 契约事实按经验沉淀。
- **热漂移自查**：同配置「冷窗 / 热窗」两测即可判定漂移量；有这组证据才可裁重复次数。
  **因裁剪被清理掉日志的阶段分解必须标「推算值」，不得当实测引用。**
- **推算值纪律**：基线拆分若为推算，明确标注且**不参与任何结论**。
- **框架未提供的特性**：标注「框架未提供」+ 证据，不留空、不虚列。

## 8. 维护与更新

- **触发（方法学变化，而非某框架版本）**：本文件是域级通用方法，**不随框架版本 / 模型换代维护**——
  只有 §1 的归组判据（「是否换入外部训练权重」）或训练感知组的四类手段集合变化、§2 四步回路增删、
  §3 三条前置契约（步数语义 / 装载计数 / 组件契约）任一条被证伪或补充、§4 三件判定法（比值法 +
  逐步墙钟 / 质量分层 / 字节级等价）判据改口径时才改本文件。
- **触发（引用面）**：§7 索引指向的真源改名 / 迁移时（`framework-support-matrix.md`「训练感知」表、
  `dit-perf-opt/references/combination-search.md`、`accuracy-gate/references/quality-gate.md`）
  同步索引；某框架的开关名 / 版本边界漂移属框架差异，只改该框架的 enablement 文件与矩阵格，不动本文件。
- **复核方法**：任取一个在库的训练感知档，按 §2 四步走一遍即可判定本文件是否仍成立——§3.1 用装载日志
  核「评估次数 vs 区间数」语义、§3.2 核三项装载证据（目标模块计数 / rank 与形状声明 / 每个 worker 激活）
  是否齐、§3.3 用 `strict` 载入 + 参数计数验证构造契约；再按 §4.3 对开 / 关两档各独立跑一次比 md5，
  确认「字节级等价 = 从未生效」仍可判。任一条不再能用**一条可执行核对**判定通过 ⇒ 该条描述需重写。
