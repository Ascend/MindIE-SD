## 1. 等价分层判据（先分层，再谈验收）

| 层级 | 判据 | 关键约束 |
|---|---|---|
| L1 逐位 | `torch.equal` 成立，且**逐形状**成立 | "平均误差很小"不构成 L1 |
| L2 数值门 | 差异落在**写明并给理由**的阈值内（SNR / 相对 L2 / max\|Δ\|） | 必须说明下游容差，不许含糊放行 |
| L3 有损门 | 质量指标 + 视觉判卷 + off-identity（见 `quality-gate.md`） | 只在有损档启用；结论必须落成档位声明 |

- **层不能混用**：层一旦改变（如为了性能下转 dtype），必须显式改口径，不得沿用"无损"名义交付。
- **"极小"仍不是逐位**：任何非零差异都判非 L1，只能走 L2/L3 并显式声明。

## 2. 实现期判据（写实现时就该满足，不是验收期补）

1. **断言进代码**：per-shape `torch.equal` 自验证写进实现，把等价性从"声明"变成"运行时事实"；
   bug 应在**第一次调用**暴露，而不是等端到端产物对比。
2. **逐形状验证**：等价性常常是**形状的函数**（分块 / 相位 / 边界条件相关）；判据是"每个形状都断言过"。
3. **前置条件不满足就回退**：写成显式判断 + 走原路径 + 打日志，绝不给"不等价的静默结果"。
4. **中间张量也要对拍**：重写错误常出在中间相位 / 顺序上，只对拍最终输出会漏。
5. **门控与回退**：新实现 env-gated、默认关；留一行回退并记录原文件 md5。

## 3. 否决形态学（每条都是"判据"，具体读数见会话产物目录归档）

| 形态 | 判据 | 结论 |
|---|---|---|
| **换写法 ≠ 换实现** | 改写后是否落到**不同 kernel**（设备侧 kernel 名 / 耗时是否变化） | 同 kernel 同速 → 白干，否决 |
| **产物字节变了** | 端到端产物 md5 / 字节数是否与基线一致 | md5 改变 → 判非无损（若收益又落在噪声内，直接回退） |
| **"极小"仍不是逐位** | 差异量级 | 非零即非 L1 → 只能降级声明 |
| **链过长** | 融合 / 改写的段数与该段字节不等比例 | 中间态越多越难保逐位 → 先缩短链 |
| **减少调用数 ≠ 减少时间** | 设备侧**总账**（新增的大算子是否吃回收益） | 只看调用数会误判 → 看总账 |
| **等价 ≠ 可用** | 峰值显存 / 交换量 / 是否需要额外副本 | 数值等价但 OOM → 否决 |
| **重叠变串行** | 该算子原本与谁重叠 | 把重叠改成串行 → 先算清与谁重叠 |

### 3.1 位级不可达时的「效应判定」：与**自然波动**比，不与 0 比

当位级一致确实不可达（或代价不可接受）时，正确的问题不是"差异是不是 0"，而是
"**这点差异与模型自身的自然波动相比如何**"。四条口径：

1. **标尺必须同类**：本仓口径 = **同配置换 seed**（同单位、同类，且正是"观众无法区分"的那种波动）。
   判据形式（**跑前登记、事后不改**）：`min(自然波动指标) < (被测差异指标)` ⇒ 可接受；
   与"另一个已实现的有损改动"比是**另一个问题**（工程比较），**不能替代可感知性判据** ✗。
   本仓一条实测形态：自然波动的 MSE 是被测差异的**数十倍**、MAE **数倍**（余量**十 dB 量级**）。
2. **负对照两次**：① 同文件与自身比；② 同一路径两次运行比 —— 都应给出"无穷好 / 零差异"，
   且**确认真的产出了产物**（不是空转 / 加载失败）。
3. **正对照一次**：用一条**已建立的读数**复现（逐位复现此前记录的指标），证明度量链路本身没变。
4. **度量必须在"用户拿到的东西"上做**：**中间量（单层 / 单次调用）的元素差异计数与端到端产物差异
   之间没有换算关系** ✗ —— 本仓有人把"**单层 attention 输出张量**的规模"当成端到端潜在差异引用，
   而真实端到端效应是**数百次调用的扰动累积 + 解码 / 码率分岔**。
5. **必须写明度量里含谁**：有损编解码会**放大并混入自己的响应** —— 本仓一条实例里视频载荷只差
   **不到半个百分点**，解码后差异却扩大到**接近全像素量级** ⇒ 结论必须标注
   "该指标**含编码器响应**"，否则会被读成"模型 / 算子本身的差异"。

6. **等价性可以"反用"来选档**：当两个档位（开关 / 流水线配置）**产物逐字节相同**时，
   保留**稳定性更好**的那一档 —— 本仓一条实例：某流水线开关的两个档位产出**同一个产物**，
   而其中一个档位**连首个请求都服务不了** ⇒ 该档是**纯负债**，关掉它**零正确性风险**。
   （判据顺序：先证等效 → 再看稳定性 → 取稳的那档；**不要**因为"它是交付档"就保留它。）
7. **中间量对拍的口径**：中间量对拍用于**定位**（哪一层/哪一步先分叉），
   **不能**用来推算端到端效应的量级（见第 4 条）。

### 3.2 非确定性算子的输出**不能**作为等价门

**判据**：若被测算子对其**明确规定的输入**都不保证逐位可复现，则**不得**用它的输出做 `torch.equal` 门。
这类算子的输出**不是**被测改动的函数，用它做门只会产生两种结果：**假阳性**（把没问题的改动判失败），
或**把门放宽到能通过**（门失去意义）——两者都会让"已验证"这一结论失效。

**如何判定一个算子非确定性（判据，不是假设）**：用**同一批输入**调用它若干次
（同张量、同前置掩码、有序等待），逐次比较输出。**出现任何非零差异即判非确定性**，
差异量级只用于记录，不改变结论。

**处置**：

1. 把门移到该路径上**确定性**的量上：掩码、载荷（payload）、scale，以及**调度层行为**
   （调用次数、调用顺序、事件依赖）；
2. 逐 chunk 的确定性中间量可入闸；
3. **调度类改动**（只改流/事件、不改算子）本应逐字节，但门必须建在**确定性张量**上，
   否则会因为下游算子的不确定性而误报；
4. 报门结果时**写明哪些量是确定性的、哪些不是**，不得把不确定量混进"0 差异"的表述里；
5. 非确定性算子的**上游**改动仍可用它下游的确定性量做门——**不要**因为找不到确定性出口就放弃入闸。

## 4. 结论有效性与复核

- 判据稳定、**读数不稳定**：硬件 / 驱动 / CANN / 框架版本、形状 / 分辨率 / 时长 / 分块参数、dtype、
  权重与预处理约定、并行拓扑与卡数、窗口与邻居负载——任一条变化，旧结论作废，必须重测。
- 收益一律**同窗**对照（口径见 `../../perf-gate/SKILL.md`），
  跨窗口绝对值不可比。
- 每条结论带**证据卡**：口径（机器 / 形状 / 窗口 / 权重）+ 判据（哪一层、阈值、地板）+
  失效信号（出现什么说明结论过期）。
