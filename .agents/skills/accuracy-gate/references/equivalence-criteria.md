# 等价性判据摘要（判据单点 · 不含实测记录）

> **性质**：本文件只保留**可迁移的判据**与**否决形态学**。原先随判据附带的案例叙述与实测数字
> （单次耗时、加速比、md5 值、SNR 读数等）**已按 `.agents/README.md` §7「实测记录 → 会话产物目录，
> 不入 skills」出库归档到会话产物目录**（`{run_results_dir}/archive/`）：它们只在当时的环境
> （机器 / 形状 / 版本 / 窗口）成立，写进 skills 会被误读为该组合的预期值。
> 需要复核某条判据的原始读数时，去归档目录找对应实验记录，**不要**在本文件里找数字。
>
> 本文件是精度验收标准 `../SKILL.md` 的判据速查；分层定义与三级验收序见该文件。

## 1. 等价分层判据（先分层，再谈验收）

| 层级 | 判据 | 关键约束 |
|---|---|---|
| L1 逐位 | `torch.equal` 成立，且**逐形状**成立 | "平均误差很小"不构成 L1 |
| L2 数值门 | 差异落在**写明并给理由**的阈值内（SNR / 相对 L2 / max\|Δ\|） | 必须说明下游容差，不许含糊放行 |
| L3 有损门 | 质量指标 + 视觉判卷 + off-identity（见 `quality-gate.md`） | 只在有损档启用；结论必须落成档位声明 |

- **层不能混用**：层一旦改变（如为了性能下转 dtype），必须显式改口径，不得沿用"无损"名义交付。
- **"极小"仍不是逐位**：任何非零差异都判非 L1，只能走 L2/L3 并显式声明。

## 2. 实现期判据（写实现时就该满足，不是验收期补）

1. **断言进代码**：per-shape `torch.equal` 自验证写进实现，把等价性从"声明"变成"运行时事实"；
   bug 应在**第一次调用**暴露，而不是等端到端产物对比。
2. **逐形状验证**：等价性常常是**形状的函数**（分块 / 相位 / 边界条件相关）；判据是"每个形状都断言过"。
3. **前置条件不满足就回退**：写成显式判断 + 走原路径 + 打日志，绝不给"不等价的静默结果"。
4. **中间张量也要对拍**：重写错误常出在中间相位 / 顺序上，只对拍最终输出会漏。
5. **门控与回退**：新实现 env-gated、默认关；留一行回退并记录原文件 md5。

## 3. 否决形态学（每条都是"判据"，具体读数见会话产物目录归档）

| 形态 | 判据 | 结论 |
|---|---|---|
| **换写法 ≠ 换实现** | 改写后是否落到**不同 kernel**（设备侧 kernel 名 / 耗时是否变化） | 同 kernel 同速 → 白干，否决 |
| **产物字节变了** | 端到端产物 md5 / 字节数是否与基线一致 | md5 改变 → 判非无损（若收益又落在噪声内，直接回退） |
| **"极小"仍不是逐位** | 差异量级 | 非零即非 L1 → 只能降级声明 |
| **链过长** | 融合 / 改写的段数与该段字节不等比例 | 中间态越多越难保逐位 → 先缩短链 |
| **减少调用数 ≠ 减少时间** | 设备侧**总账**（新增的大算子是否吃回收益） | 只看调用数会误判 → 看总账 |
| **等价 ≠ 可用** | 峰值显存 / 交换量 / 是否需要额外副本 | 数值等价但 OOM → 否决 |
| **重叠变串行** | 该算子原本与谁重叠 | 把重叠改成串行 → 先算清与谁重叠 |

## 4. 结论有效性与复核

- 判据稳定、**读数不稳定**：硬件 / 驱动 / CANN / 框架版本、形状 / 分辨率 / 时长 / 分块参数、dtype、
  权重与预处理约定、并行拓扑与卡数、窗口与邻居负载——任一条变化，旧结论作废，必须重测。
- 收益一律**同窗**对照（口径见 `../../perf-gate/SKILL.md`），
  跨窗口绝对值不可比。
- 每条结论带**证据卡**：口径（机器 / 形状 / 窗口 / 权重）+ 判据（哪一层、阈值、地板）+
  失效信号（出现什么说明结论过期）。

## 5. 维护与更新

- **更新触发条件**：§1 三层表的层名与判据（L1 `torch.equal` / L2 数值门 / L3 有损门）、§3 否决形态学的形态名
  （如「换写法 ≠ 换实现」「等价 ≠ 可用」）、§4 失效轴清单任一项改写，或 `quality-gate.md` /
  `../../perf-gate/SKILL.md` 的口径变动 ⇒ 本文件对应引用须同步。
- **复核方法**：任取 §3 一行形态按其判据做一次最小核对（如对同一改动核对设备侧 kernel 名 / 耗时是否变化）；
  结论与表内写法不符即该行失效。本文件不存读数，新读数一律进 `{run_results_dir}/archive/`，不得回填。
