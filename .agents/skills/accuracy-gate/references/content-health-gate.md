# 内容健康度门（无视觉输入时的机读替代 · 且不只是替代）

> 方法文档。**本文件是精度验收标准 `../SKILL.md`（`accuracy-gate`）三级验收第三级的并列子门**：
> `quality-gate.md` 管"定量 + 视觉 + off-identity 三门"的**流程与阈值校准**；本文件管两件它没管的事——
> ① **没有视觉输入时"内容还在不在"的机读判定**，② **载重件场景下 off-identity 的正确对照取法**。
> 分工：**不重复** `quality-gate.md` 的门禁流程、`evals/` 契约与校准规则；本文件只给
> 「机读量的取数口径 + 判据 + 归因纪律」。
> 定位：本门**不是视觉门的等价物**——不得把"机读通过"写成"视觉通过"；它的价值是
> ① 无图像输入时的**唯一可机读塌陷判别**；② 有视觉输入时**先跑的快速否决门**（塌陷档先被拦下，省一次判卷）。
> 术语：**塌陷** = 生成内容消失或退化（动不起来、整片压黑/过曝、只剩平坦噪声），
> **不是**"与参考不同"。把这两件事分开，就是本文件存在的全部理由。

## 何时用（触发）

- 执行侧**无图像输入**，视觉门只能记 `inconclusive` / 待判，但仍须回答"这一档能不能用"；
- **有损档 / 换入外部训练权重档**（少步蒸馏适配器、VAE 解码替换）的产物级判定；
- 某个特性是**载重件**（关掉它就不出图 / 出坏图）而要做 off-identity 归因时；
- 已有**纯数值 / 离线研究**给出"与参考更远"的结论，要用**服务端产物级 A/B** 收口时。

## 四个机读量（取数口径 + 判据）

对每条臂的**最终交付产物**取数（不是中间 latent），且同 prompt / 同 seed / 同分辨率 / 同帧数 / 同步数：

| # | 量 | 取数口径 | 判据 |
|---|---|---|---|
| ① | **时序活动度** | 相邻帧**逐像素平均绝对差**（全片汇总；尺度写明是 0–255 还是 0–1） | 塌陷档显著低于同窗健康档族。**本文件的主判据**——"动不起来"是最强的塌陷签名 |
| ② | **亮度分布** | 全片**均值 / 标准差**（逐帧均值、标准差的汇总统计） | 均值或标准差偏离同窗健康档族：整片压黑 / 过曝 / 对比塌平。标准差过低 ⇒ 画面趋于平坦 |
| ③ | **产物体积量级** | 产物字节数（**同编码器 / 同容器 / 同分辨率 / 同时长**下才可比） | 塌陷档明显偏小（编码器对低信息量内容给更少字节）。**只作量级旁证**，单独不判 |
| ④ | **确定性** | **同配置多请求**（≥2，建议 4）产物**逐字节一致**（md5 + 字节数都记） | **逐字节一致本身就是判据**：不一致 ⇒ 该档的 A/B 不可解释，先按 `../SKILL.md` 第一级解释确定性来源，再谈内容健康 |

> ④ 是①②③的前提：**没有确定性，读数无法归因到配置**（差异可能来自运行本身）。
> 四量必须**同窗**取（同一次实验窗口内所有臂一起跑）；跨窗读数不可比（同 `../perf-gate/SKILL.md`）。
> ①②③ 是**带内/带外**判定，所以必须同时知道"健康带"在哪——见下节。

## 关键判据：「距参考远」≠「塌陷」

**规则：跨配置的定量相似度（PSNR / 灰度相关等）只能作登记与回归对比，不得用来判"能不能用"。**

**现场取数方式（双向标定 / bracketing）：**

1. 对**同 prompt / 同 seed**的不同配置（至少两档）**各抽相同帧号**做统计；
2. 从**已知健康档**（交付档 / 权威参考档）与**已知塌陷档**（典型：载重件去掉后的臂）各取一组读数
   ⇒ 得到该模型该任务上的**健康带**与**塌陷带**；
3. 用这条带**标定本次待判档的阈值**，看它落在哪一带——阈值每次**现场标定**；
4. 阈值**不跨任务类型 / 模型迁移**：视频有轨迹混沌、图像无帧轴，量级不可互抄，各自标定。

**为什么相似度不能当门槛**：扩散同 prompt 异配置天然是**混沌轨迹**——同一配置两次运行可以逐字节一致，
但换一个精度档或融合门，相似度会掉到"很低"；此时**塌陷档与健康档的相似度区间可以互相交叠**
（实测形态：塌陷档对某参考的相似度**高于**同精度精确算术版对照档）。⇒ 该指标在本任务上**无判别力**，
当门槛会两头出错：把健康档判死、把塌陷档放过。

**复核方法（这条结论怎么才算仍成立）**：每次判定前做一次**判别力自检**——把已知塌陷档与已知健康档
都过一遍该指标；若塌陷档读数**不低于**健康档，则该指标在本任务上**不可作门槛**（登记为"仅登记/回归用"）。
只有它能稳定分开两带时才允许写阈值。**出现"阈值判死健康档 / 放过塌陷档"即本条失效，重做标定。**

## 载重件的 off-identity 会反转

**规则：off-identity（"关掉该技术应恢复 baseline 行为"）只对"可关"的特性成立。
对载重件——缺了它就不出图 / 出坏图的特性（典型：少步蒸馏适配器、必需的解码器）——"关掉"
不是回到基线，而是换成了一个**不同的、通常直接塌陷**的生成任务。**

正确对照取法：

- **不要**用"关掉"作 off-identity；
- 取**同一精度的精确算术版**作对照：**运行时施加** vs **离线合并**（`W' = W + (α/r)·B·A` 之类）
  ——两者算的是同一件事，差别只在施加方式；
- 判据两条：① 精确算术版须落在**健康带**内（证"模型被救活"）；② 合并版与运行时版的相似度
  **是否优于"换一个精度档"这一档变化**。若两者**同一量级** ⇒ 合并只是**可用的近似**、
  **不是**精确复现，须按 `quality-gate.md` 落成**档位声明**，不得宣称"等价于运行时施加"。

**为什么**：低精度下把 delta 合并进权重会**吞掉适配器本身**——每元素增量小于该 dtype 的一个量化步长时，
舍入误差与增量同量级、甚至更大 ⇒ 合并版与精确版的差异，能与"直接关掉适配器"造成的差异**同量级**。
⇒ **"不能精确复现适配器"与"不能用"是两件事**：前者由本门如实登记（衰减量进登记列），
后者只由内容健康度（上节）与视觉门判。

**复核方法（这条结论怎么才算仍存在）**：

- **该特性是否仍是载重件？** 判据 = **把它关掉，产物是否仍在健康带内**——若关掉后内容正常，
  它就不是载重件，"反转"处理不再适用，改回 `quality-gate.md` 的标准 off-identity；
- **合并的精度门槛是否仍成立？** 判据 = 目标权重 dtype 的**一个量化步长**与该适配器
  **每元素增量量级**之比。现场取数：任取若干目标模块，比较 `|W'−W|` 的分布与权重的最小可表示间隔；
  **步长 ≥ 增量 ⇒ 合并会吞掉适配器**，本条适用；步长 ≪ 增量 ⇒ 合并可能已足够精确，须重测。

## 纯数值研究只能否掉"等价性"，不能否掉"可用性"

**规则**：任何只在**激活空间 / 权重空间**度量"与参考的距离"的研究，结论上限是
「该改动**不是**参考的精确复现」；**不得**据此判「该改动不可用」。
"能不能用"必须由**服务端产物级 A/B** 收口：真实服务、真实请求、同窗两臂、
产物过本文件四量 + 视觉门。

- **反例（越权）**：离线研究报告以"合并后的权重距参考比直接关掉适配器更远"为据，
  建议**不采用**某条合并路线——它只证明了"不精确"，且**从未跑服务端 A/B**（窗口已备但未执行）。
  服务端实测的结论**完全相反**：合并档产物落在健康带内（可用）、路线成立；
  被否掉的只是**等价性**，不是**可用性**。
- **正例（合规）**：同一路线在**离线**给出"不精确"结论的同时，**另跑**同窗服务端 A/B
  （控制臂 = 原交付档、实验臂 = 合并档，各多请求、各自产物逐字节一致），
  以产物级内容健康度 + 视觉门收口 ⇒ 结论为「可用，但适配器动态效果有**系统性衰减**，
  须由视觉门判定关键内容是否还在」——**衰减量是登记量，不是门槛**。

**归因纪律**：数值研究给出的"更远 / 更近"只能进**登记列**；任何"采用 / 否决"的方向结论
都必须附**服务端产物级 A/B 的证据指针**（见「归档指针」）。缺该证据的方向结论按
`../perf-gate/SKILL.md` 的入库门处理，**不得写入总览表**。

**复核方法**：见到"某数值研究否掉了某路线"的结论时，先问**它有没有服务端产物级 A/B**——
没有 ⇒ 该结论只对"等价性"有效，须重新执行服务端对照（本判据的来源案例已经实测反转过一次）。

## 判定要点

- **机读量只判"塌陷"，不判"好坏"**：过门只说明内容还在、还能出图；画质档位与可接受性仍归
  视觉门（`quality-gate.md`）与档位声明。
- **视觉门不可用时**：记 `inconclusive`（成因按 `quality-gate.md`「判定要点」三种成因分开标注）
  **＋ 附机读存证**（四量读数、逐帧亮度存证、并排蒙太奇）；机读存证**不得**写成视觉门结论。
- **四量的口径比数值重要**：帧率 / 时长 / 分辨率 / 编码器 / 容器任一变化 ⇒ ①②③ 全部不可比；
  改变取样帧号同样不可比。**同窗、同取数脚本**是硬前提。
- **环境作用域（强制）**：本文件的比值门限（"显著低于/高于"、"同一量级"、"2 倍以上"）来源是
  **一次「硬件 + 拓扑 + 软件栈 + 模型」组合的快照**，不是普适事实。换任一维度后**必须本地重新标定**
  （重取健康带与塌陷带），再判本次读数。
- **结论有寿命**：模型换代 / 换任务类型（视频↔图像）/ 换扩散步数预算 / 换适配器版本后，
  健康带会整体移动 ⇒ 按上面各节"复核方法"逐条复核，不再复现的条目直接删除，不留"以防万一"。
