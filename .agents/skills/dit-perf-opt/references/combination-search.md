# 有损组合试验设计（S4-2 · 组合搜索协议）

> 定位：S4 多特性组合（量化/稀疏/缓存/步数等）的**试验协议**——把「全对组合矩阵盲试」
> 升级为「seam 静态判定 + 单变量叠加 + frontier 保留 + 层回退」。方法改编自跨栈组合搜索方法论（compose/search 思路）：能力契约与互斥 seam 思想与硬件
> 无关，仅借结构；seam 表取值以 `framework-integration/references/framework-support-matrix.md`
> 的支持状态（+ `docs/zh/features/*` 特性真源）与首次真实组合
> 试验校准为准。

## 何时用

- S4 需同时开启 ≥2 个有损维度时；
- 单特性有损判定直接用 `../../accuracy-gate/references/quality-gate.md`（精度验收标准），不进入本协议。

## 纪律（先于一切步骤）

1. **一次一变量**：只在前一已验收组合上加 1 个特性；多变量同时上无法归因收益。
2. **单特性先过门**：进入组合的每个维度先单独过 quality gate（`../../accuracy-gate/references/quality-gate.md` + 仓库 `evals/`）。
3. **跨 seam 组合优先**：作用在不同 seam 的维度收益近似可加（见 seam 表），先做这类组合。
4. **frontier 保留**：组合仅在「质量不降（gate pass）且首步耗时下降」时保留；其余记录原因后丢弃。
5. **无损项叠加复核**：有损叠加后复核既有无损项（融合/并行）是否仍有效，被稀释即回退
   （呼应 model-auto-optimization 的 S4 纪律）。
6. **静态前置判据先于叠加**：进组合前先静态核对**后端几何 / 布局前置**（如某稀疏后端要求层声明视频轴
   layout `qkv_layout='BSND'`；不满足时运行期静默走 dense 兜底 = 白跑）与**框架是否有该路径**
   （无接线时按「覆盖范围声明」登记 ❓，不虚列）。**fail-closed 判据**：兜底日志（如 `staying dense`）
   与 lossless 输出**逐字节相同** ⇒ 判「未生效」，须穷尽档位后按「豁免前置 = 形态穷尽」登记豁免，
   **不得**记作「收益近似为零」（未生效 ≠ 收益小）。
7. **参数面档位扫描与主导旋钮辨识**：同一维度的参数面（阈值 / 窗口 / 稀疏度 / 步数…）逐档扫描时
   **一次只动一个旋钮**，先**辨识主导旋钮**（决定墙钟的是谁、决定质量的是谁）；**平坦区**
   （决策与输出一致）不细扫，**过紧档**要记录「少命中反而变慢」。档位结论一律标注「本组合观测」，
   换框架 / 模型 / 负载规模**重扫**（同「单点结论不跨规模迁移」）。
8. **同窗括窗 + 逐组合参与证据**：组合（补测）轮的行必须**同窗**——批首 / 批尾各跑一次 lossless
   **括窗**消除窗漂移；每档 serve 内先 warm 再取若干稳态请求；**组合的技术参与证据**用服务日志的
   特性 active 计数 + 抽样步 kernel 采集，**不是只看墙钟**（防 no-op 假加速）。

## 必测组合覆盖集（S4-2 强制 · 防静默缺行）

> 背景驱动：组合闭环中曾出现"组合矩阵只含已选候选链、漏掉跨 seam 合理两两与全维度三元"
> （如量化×稀疏、稀疏×Cache、Cache+量化+稀疏 缺行）——**frontier 收敛 ≠ 组合空间被覆盖**。
> 本节把「每个有损组合必须有裁决」显式化为强制清单：不允许静默缺行。

### 触发与必测集

- **触发**：特性覆盖清单判定 `量化` / `稀疏` / `Cache` 中 **≥2 个为「做」且各自有通过 quality
  gate 的单点 frontier** → 进入 S4-2 前先建「组合覆盖清单」。
- **必测集**（三个维度单点 frontier 齐备时，全部必须裁决）：

| # | 必测组合 | seam 判读 | 叠加说明 |
|---|---------|-----------|---------|
| 1 | 量化 × 稀疏 | 跨 seam（precision × attention_backend） | 直接叠加，无窗口冲突 |
| 2 | 稀疏 × Cache | 同 seam（step_decision，窗口可分） | seam_check 报 warning → 先静态确认窗口错开/只留最强档；首案例校准：默认同窗口可叠 |
| 3 | 量化 × Cache | 跨 seam（precision × step_decision） | 直接叠加 |
| 4 | **Cache + 量化 + 稀疏（三元）** | 跨 seam + step_decision 窗口可分 | **必须实测或显式豁免**（见下）；即 SKILL S4 目标档「8bit + 稀疏 + cache」 |

  当某维度在 framework×模型下不可用（support-matrix ❌/staying-dense/无单点）时，含该维度的
  必测行自动降级为「豁免」，但仍须登记原因——不豁免缺失，只豁免"某个维度不存在"。

### 裁决三态与收口

- 覆盖清单每行状态：`已测`（retain/reject，带 gate 证据） / `豁免`（框架不支持 / 能力互斥 /
  staying-dense / 同 serve 跨树不可行等，**带证据指针 + 形态穷尽清单**） / `未裁决`（禁止 close）。
- **豁免前置 = 形态穷尽（fail-closed，2026-09-08 收紧）**：申请豁免前必须**穷尽该组合在本环境
  的所有可测形态**（各 mindiesd 树、各精度档、各 sparse/cache 档、各并行形态…），逐形态给
  「已试 / 不可行 + 证据路径」；**只有所有形态均不可测（或均无意义）才允许豁免**。登记字段：
  `形态穷尽清单`（形态 × 尝试结果 × 证据），缺此清单 = 豁免无效（close 复核项）。
  ⚠️ 反例教训（2026-09-08）：qxs 曾以「CMP 快量化 × 028 sparse 跨树不可行」豁免——但 028 树
  慢量化形态**可实测**（且 cache 主导下不慢）→ 豁免不当，须撤销并实测。区分：**「某形态不可行」
  ≠ 「该组合不可测」**——只要存在一个可测形态（哪怕非最优档），就必须实测并注明形态约束；
  不可行的形态只在「说明」列登记，不构成整行豁免。
- **必测优先于自由候选**：先让必测集全部有裁决，再做探索性候选与 frontier 扩展；预算到点只可
  停自由候选，**不得把必测组合留作「未尝试」进 detail-report §C**——确未测者必须转「豁免」并写明阻断。
- **三元不达标不静默删行**：按层回退（降档 / 错窗 / 整维回退）并记录该组合的回退裁决与最终边界。

### 组合语义与命名（2026-09 定稿）

- **量化组合代表档 = `w8a8f8`**：量化与其他特性的必测组合一律以 w8a8f8 为代表档参与，在候选
  组合中选**最高性能**的组合；
- **Cache 与时间步优化二选一**：同一条组合/对比行只取其一（时间步为步级横切项，不与 Cache 并存
  于同一组合行）；
- **试验记录命名**：分类直接写 `算子(稀疏度xx%)`（如 `rf_v2(80%)` / `EagleQBSA(80%)`，稀疏×FA
  量化新算子标注 mask 算法与量化规格）；量化行带 `w8a8(mxfp8)` 式规格标注；
- 稀疏与量化(f8)叠加产生的新算子：按 mindiesd 算子性能分析，框架未接入先本地 benchmark 后再定
  接入（优选取性能者 + 对应 mask 算法）。

## seam 声明表（草案 v1，首案例校准）

| seam | 含义（MindIE-SD 语境） | 涉及维度 | 组合规则 |
|---|---|---|---|
| precision | 同一 MatMul/Linear 的数值精度档唯一 | 量化档 × 融合 kernel（pattern） | 同 seam 至多一个 writer；量化档 × 融合 pattern 须先确认 kernel 接受量化输入/图形态匹配，否则运行期 fallback → 组合前查 `framework-support-matrix.md` 支持状态 |
| attention_backend | 同一 attention 一次只一个后端 | FA / 稀疏 FA / 融合 FA（含 BSA） | 稀疏度参数与后端选择同 seam；同层只留最强档 |
| step_decision | 哪些 step 全稠密/稀疏/被缓存复用 | 缓存（dense_steps/阈值）× 稀疏（dense_steps/路由） | 同一 step 窗口内只允许一个 writer；不同窗口（phase）可叠加 |
| token_semantics（预留） | token 集合语义一致性 | 未来 token prune × 稀疏 attention | 共享 token 语义，先静态判再叠加 |
| vae_seam | VAE 编解码精度/编译 | VAE 编译、VAE 精度 | 独立于 DiT 侧维度，可自由叠加 |

> 读法：跨行（不同 seam）组合 → 直接进 Step 2；同行（同 seam）组合 → 只保留最强档，
> 不做双 writer 叠加。

### seam 表首案例校准（2026-09-05 · H3 × vLLM-Omni V1；开启方式见 `../../framework-integration/references/vllm-omni-enablement.md`，实测记录归档于会话产物目录 `{run_results_dir}/archive/`）

- precision × attention_backend 跨 seam 可叠加：INT8（MatMul precision）与 稀疏 mix（attention 内量化）同开有效（同窗相邻对判定）。
- attention_backend 同 seam：bf16 稀疏 vs EagleQBSA mix 取最强档（mix 更快、**质量略降**——同档
  **SSIM 降幅为个位数百分点量级（差值远小于 0.1）**，本组合观测；读数见归档
  `{run_results_dir}/archive/vllm-omni-minimax-h3-case.md` §4 与
  `{run_results_dir}/archive/lightx2v-mindiesd-case.md` §11 P2）；不同档算同 seam writer，勿双叠。
- step_decision：Cache × 稀疏同 step 窗口可叠加（默认 cache 即生效），未见 dense_steps 冲突；收紧
  `max_continuous_cached_steps` / `threshold` 可得质量优先档（以墙钟代价换质量）。
- **稀疏档质量非线性**：更小的稀疏档端到端质量反低于更大的稀疏档（轨迹敏感性）→ 组合前稀疏参数须逐档端到端 gate，
  不可按密度线性外推（呼应基准扫描纪律）。
- **单点行归因**：组合链必须含每特性的「单点行」（最强档单独、其余有损关）——首版缺「单独 Cache」单点被
  审阅发现；补测 Cache 单点（lossless 基底，默认档）后，与另一分辨率负载的 cache 单点降幅
  **交叉一致**（同量级）→ **cache 是最轻损维度**（默认档质量即可接受，故常作组合基底）。
  质量读数与档位数值见归档 `{run_results_dir}/archive/`。
- **质量绝对值口径**：组合 / 并行档质量一律 = **vs 同构 lossless**（同 seed 对拍）；「有损 × 并行」
  交叉对比（不同并行形态同档）只作次级参考，不替代「vs 同构 lossless」作对外数值
  （读数见归档 `{run_results_dir}/archive/`）。
- **覆盖范围声明**：mix（attention 内量化，EagleQBSA）的 int8 只覆盖稀疏块路径，dense FA 兜底 bf16
  （FA 兜底 4/步计数）→ 对外表述与报表量化修饰符（如 `f8`）必须写明覆盖范围；全注意力 8bit 未实现时
  标 ❓ 不虚列（报表命名/对照组规则见 model-auto-optimization `overview-report.md` §2.1–§2.3）。
- 跨窗口声明：frontier 判定以**同窗相邻对**为准（本机不同窗口绝对 e2e/首步耗时有 ~±10% 热/负载漂移）；性能主口径 = e2e 完整请求墙钟（锚点实测/中间行估算），首步耗时（warmup 后第 1 步）作辅助口径用于跨步数同口径对比（见 overview-report §1/§1.1）。

### seam 表第二案例校准（2026-09 · 训练感知长视频档；只留**比例关系与方向**，绝对加速比不入库）

> 以下每条的方向结论都是**该框架 × 该模型 × 该规模下的观测**，**不是可复制的执行序**；
> 换框架 / 换模型 / 换负载规模必须按本文件协议**在任务内重判**。

- **单点收益排序随规模反转 ⇒ 单点必须在本任务口径下测**：同一框架同一模型，长序列档
  **削注意力的维度 > 缓存维度 > 线性层量化维度**（三者单点收益依次递减），而短序列档是缓存维度
  主导。成因：序列变长后注意力 O(S²) 成为主项（稀疏削的正是它），线性层量化的占比被稀释。
  **禁止引用其他时长 / 分辨率 / 拓扑的单点排序来裁剪本任务的候选**（与「单次结果不迁移」同源，
  但这里漂移的是**输入规模**而非框架；换规模 = 新对照）。
- **同一方法在不同框架下收益不同 ⇒ 方向也不同（能力实体差异）**：起作用的「能力实体」不同——
  有的框架把某能力做进融合 op，有的只有 eager 路径，有的干脆未接线（见
  `framework-integration/references/framework-support-matrix.md`）——
  故**同一维度在不同框架的单点收益与协同关系不可互推**。配置组合前先核该框架列的**能力面**，
  再按本任务实测定方向；**禁止把某模型的优化路径当路线图移植**。
- **协同定位法（最省卡的一步）**：交互强度 = **实测加速比 ÷ 各单点加速比之连乘**。≈1 = 独立
  （可连乘估算）；明显 >1 = 正协同；<1 = 相互稀释。本案例观测：缓存×量化、缓存×稀疏 **≈1（独立，
  可连乘估算）**，量化×稀疏**明显 >1（正协同，+20% 量级）**，且三元实测可由「两两 × 剩余单点」
  **完全解释** ⇒ **三元可只测一次即完成归因**（能否被完全解释 = 归因是否完成）。
- **机理必须用逐步墙钟证，别停在相关性**：本案例量化维度的**边际收益随注意力被压缩单调上升**
  （单点很小 → 稀疏之上更大 → 稀疏+缓存之上最大）——这正是正协同的直接证据（Amdahl）。
  **工程含义：某特性单点收益低 ≠ 该特性可裁**；按单点收益裁剪候选会误删正协同来源，
  判据是「边际收益随其他维度加压的变化方向」。
- **「未生效」≠「收益小」，判据是字节级等价**：少步档开 / 关缓存，两次**独立**运行产出的产物
  **md5 完全相同**、质量指标同值 ⇒ 该维度从未生效（其预热/预算参数吃满了少步档的全部步数预算）。
  该维度应**整体剔除**而非作「收益近似为零」登记；字节级等价是比加速比对比更强的未生效证据。
- **训练感知（换权重）档与免训练有损档可叠加，但须重审生效性**：本案例换权重档上量化 / 稀疏
  照常生效（连乘量级成立），但缓存因步数预算骤降而**结构性失效** ⇒ **换权重档落地后必须按
  post-enable-review 重跑各维度「是否仍生效」判定**（而非只复测墙钟）。
- **框架无路径的行必须显式登记，不得静默缺行**：本案例三元 `Cache + 量化(w8a8f8) + 稀疏`
  因该框架无全注意力 FA 8bit 接线而无实测路径 → 在覆盖清单登记 `❓` + 原因，
  不作锚点、不宣称（与 §「覆盖范围声明」同源）。

### seam 表第三案例校准（2026-09-13 · 序列并行 × 稀疏 × 掩盖；只留**比例关系与方向**）

> 契约与判据本体在 `dit-parallel-opt/references/cp-sparse-combination-method.md`（seam 机制层）
> 与 `dit-parallel-opt/references/parallel-form-selection-method.md`（形态抉择层）；本节只记
> **组合层**的规则增量。

- **并行形态不是 seam writer，但决定 seam 的可行性**：同一稀疏后端在不同 CP 形态下**可用性不同**
  （环状形态在框架侧被硬拒、且其路径会**绕过注意力后端** ⇒ 稀疏静默退化为稠密；AllGather-KV 形态
  可叠加）。⇒ 组合候选表必须**先按形态可用性过滤**，再谈收益；「框架提供该形态」与「该形态下稀疏生效」
  是两件事，要分别核。
- **「未生效」判据在并行 × 稀疏上同样成立**（与第二案例同源）：叠加臂与 lossless 档产物**逐字节相同**
  ⇒ 判**未生效**（不是「无损」），该组合整体剔除、不得登记收益。**字节级等价优先于加速比对比。**
- **正协同 ≠ 整体更快（本案例最重要的组合层结论）**：序列并行 × 掩盖是**正协同**——掩盖在复合形态上
  兑现率约 100%、在纯形态上约 60%（即「并行形态让掩盖更值钱」）；但该复合形态端到端**仍慢约 10%**。
  ⇒ **协同强度只描述「两个特性互相放大」的程度，不能替代选型结论**；选型必须另走条件化判据
  （GQA / 跨岛带宽 / 形态 plumbing）。
- **载荷档变化会反转形态排名 ⇒ 组合矩阵须在载荷档变化后重跑形态对比**：任何把集合通信载荷减半的动作
  （通信前量化、低精度 KV）同时改变掩盖上限 `c/f` 与「形态自带计算」的占比，本案例观测到一次**完整
  反转**（按未解释带宽损失投影时复合形态反超约 7%，两边同时做通信前量化后排名又反回去）。
  ⇒ 组合试验的**顺序**应为：先定载荷档与量化档，再比并行形态；反过来做会白跑一轮。
- **组合层要登记的三件事**（本案例的收口形态）：① 形态可用性结论（可用/不可用/未跑通）；
  ② 叠加的生效性判据结论（逐字节等价是否出现）；③ 协同强度（实测加速比 ÷ 各单点加速比之连乘）
  与**它的作用域变量**（GQA 比例 / 跨岛比例 / 块尺寸）。三者缺一，结论不可迁移。

## 执行协议

**性能口径（同 model-auto-optimization overview-report §1/§1.1）**：性能主口径 = e2e 完整请求
墙钟——**base / 最终推荐 / 三元组合 = 实测**；中间行可估算标 `[估算]`（DiT 比例法 + VAE/其他，
公式见 overview §1.1）。性能选型/组合预筛可在少步下做（如 1 步识别收益，用首步耗时辅助口径同
口径对比，只筛方向与排序）；**进入 quality gate 的候选与最终采纳组合必须全量步数实测 e2e**
（少步结论不直接宣称）；每档/每组合登记实测步数与 e2e（实测或 `[估算]`，识别行注明「识别步数」）。

```text
Step 0 单特性基线：每个有损维度先开一档 → quality gate → 成为 frontier 单点
        （**单点须在本任务口径下测**——时长/分辨率/拓扑变化会反转单点排序，见「seam 表第二案例校准」）
Step 0.5 建覆盖清单：对「量化/稀疏/Cache ≥2 个有单点 frontier」的任务，在迭代表建 [MUST]
        必测行（两两 + 三元 Cache+量化+稀疏）——先于自由候选规划
Step 0.6 协同预判：有 ≥2 个单点时用「与单点连乘的比值」定位跨 seam 交互；比值明显 >1 的组合
        优先补全量实测（**单点收益低的维度可能是正协同来源，勿按单点收益裁候选**；
        框架无路径的行显式登记 ❓ + 原因，不静默缺行）
Step 1 静态筛查：按 seam 表排除同 seam 双 writer 与 kernel 不支持的「量化 × 融合」组合；
        必测行中同 seam（稀疏×Cache）按「窗口可分」判定，不直接排除
Step 2 逐组合叠加：先跑完覆盖清单 [MUST] 行，再做自由候选叠加（跨 seam 优先），登记候选
Step 3 验收：三层证据（图命中/kernel diff/首步耗时）+ quality gate + off-identity 复核；
       不达标 → 层回退（记名单）后复验（**回退后档位全量步数实测 e2e**，见「层回退策略」）；达标 → 保留进 frontier
Step 4 收敛与产物：覆盖清单收口（无未裁决 [MUST] 行）+ 候选登记表收尾 +
        final_report「优化方案」节 + 声明边界
```

## 层回退策略

- 触发：端到端 quality gate fail（伪影/定量超容差），或无损项被有损组合稀释。
- 顺序：先降该维度档位（稀疏度/缓存阈值）→ 再错开 step 窗口 → 最后整维回退；
  每次回退记名单（层/参数/原因）并复验；回退名单进 evidence.json 与 final_report。
- **回退必须全量实测 e2e（强制）**：对 cache/稀疏/量化任一维度发生回退（降档/错开窗口/换实现/
  整维回退后仍保留的档位）时，**回退后的最终档/边界档必须全量步数实测 e2e** 来识别性能加速
  效果——回退档是潜在采纳配置，是结论锚点，**禁止用少步识别或 `[估算]` 宣称回退后的性能**；
  回退前的高档失败数据可留少步/估算记录（进迭代表/§C），但回退后采纳的档必须实测（若该回退档
  即为最终推荐/三元组合，按 overview-report §1.1 锚点行实测）。
